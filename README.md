# أحمد للبرمجة — Ahmed BYD Voice v1.7.0

تطبيق ثيمات السيارة الخاص بأحمد — **50 ثيماً** كاملة + **تحكم صوتي بالعراقي أوفلاين وعبر الإنترنت**،
ملكية 100%، package: `com.ahmed.bydvoice`.

## الجديد في v1.7.0

- **تحكم صوتي أوفلاين كامل**: مكتبة Vosk داخل التطبيق — التعرف على الكلام يصير على الجهاز نفسه بدون أي إنترنت. أول استخدام أوفلاين ينزّل موديل العربي (~46MB، مرة وحدة بالعمر) ويفكّه داخل ذاكرة التطبيق.
- **مفتاح وضعين** بتبويب الصوت: «عبر الإنترنت» (خدمة أندرويد، خفيفة) أو «أوفلاين» (كامل). التفسير دائماً أوفلاين بـ `core:voice`.
- **حماية مهنية**: تحميل الموديل مع شريط تقدم 0–100%، فك ضغط محمي من Zip Slip، وتحرير الموارد (المايك، الموديل، الخدمة) عند الخروج.
- موديل العربي الرسمي الصغير من مشروع Vosk — تفهم العامية العراقية بعد توحيد النص (الألف/التاء المربوطة/التشكيل).

## الجديد في v1.6.0

- **التحكم الصوتي** (تبويب «الصوت»): اضغط وتكلم بالعراقي — «وضع ليلي»، «غيّر الثيم إلى الفخامة الزجاجية»، «تحقق من التحديث». التعرف عبر خدمة أندرويد (يحتاج نت)، والتفسير أوفلاين بالكامل في وحدة `core:voice` مع 12 اختبار وحدة.
- **شريحة التشخيص** بأعلى لوحة الثيمات: تبين مصدر الوضع الحالي (كشافات السيارة ✅ / الساعة 🕐 / يدوي) وحالة قراءة الكشافات — هذه هي أداة فحص إشارة الضوء على DiLink الحقيقي.
- **وحدة `core:voice` جديدة**: مفسّر أوامر نقي (JVM) يتوحّد مع أخطاء التعرف الصوتي: توحيد الألف والتاء المربوطة، حذف التشكيل والترقيم، مطابقة أسماء الثيمات بالعربي والإنجليزي. أولوية المطابقة: اسم الثيم → وضع العرض → التحديث → التبويبات (حتى «الليل القطبي» ما يتصادم مع «وضع ليلي»).
- **إذن `RECORD_AUDIO`** يُطلب وقت التشغيل فقط، والمايك يُحرَّر بـ `destroy()`.
- **سكربت `setup_keystore.sh`**: يولّد مفتاح التوقيع الدائم ويطبع قيم GitHub Secrets جاهزة للصق — شغّله على جهازك مرة وحدة.

## توليد مفتاح التوقيع الدائم (مرة وحدة، على جهازك)

```bash
bash setup_keystore.sh
```

يطبعلك:
1. `KEYSTORE_BASE64` — الناتج الطويل من `base64` (انسخه كامل)
2. `KEY_ALIAS` (افتراضياً: `byd`)
3. كلمة السر اللي دخلتها تُستخدم مرتين: `KEYSTORE_PASSWORD` و`KEY_PASSWORD`

روح لريبو GitHub ← Settings ← Secrets and variables ← Actions ← New repository secret، وأضف الأربعة.
بعدها أي تگ Push لتگ `v*` يبني APK موقّع بمفتاحك الدائم — التحديثات الجاية تثبت فوق القديم بدون حذف.
بدون الـSecrets يبقى التوقيع بمفتاح debug مؤقت (كل بناء بصمة مختلفة — يلزم حذف القديم قبل التثبيت).

## عقد التحديث (version.json)

```json
{
  "versionCode": "122",
  "versionName": "1.2.2",
  "url": "https://github.com/Alkaraonge/Ahmed_BYD_Voice/releases/download/v1.2.2/Ahmed_BYD_Voice_v1.2.2.apk",
  "sha256": "<بصمة sha256 الحقيقية للملف>"
}
```

1. **versionCode رقمي دائماً** ويتصاعد — لا تستخدم مقارنة نصوص أبداً.
2. **sha256 إلزامي** — ارفع الـAPK على GitHub Releases، احسب البصمة، ثم ارفع version.json.
3. الروابط **https فقط** — AppUpdater يرفض http برمجياً.

## قواعد التعديل

1. أي ثيم جديد = إدخال في `BYDThemeId` + إدخال في `BYDThemeRegistry.allList` + يجوز تخطي CI.
2. `onPrimary` يُشتق دائماً عبر `bestOnColor(primary)` — لا تختره يدوياً.
3. الثيم الزجاجي: surface بـ alpha ‏0xCC لأن DiLink 3 (Android 9/10) ما يدعم blur.
4. ارفع `versionCode` و`versionName` مع كل تسليم، وحدّث `version_label` بكل ملفات اللغات.
5. أي نص جديد بالواجهة = يضاف بالسترنقز **بالست لغات كلها** — لا لغة منسية.
